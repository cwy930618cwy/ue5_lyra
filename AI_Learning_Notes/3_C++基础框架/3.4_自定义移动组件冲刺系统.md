# 自定义移动组件与冲刺系统

## 架构设计

通过 `SetDefaultSubobjectClass` 在构造函数初始化列表中替换默认移动组件：

```cpp
ABattleCharacter::ABattleCharacter(const FObjectInitializer& ObjectInitializer)
    : Super(ObjectInitializer.SetDefaultSubobjectClass<UBattleCharacterMovementComponent>(
        ACharacter::CharacterMovementComponentName))
```

**关键点**：必须在初始化列表中做替换，不能在构造函数体内。因为 ACharacter 的构造函数会创建默认的 UCharacterMovementComponent，如果在体内再替换就晚了。

## 冲刺实现模式

### 双标志设计

```cpp
bool bWantsToSprint;  // 玩家意愿（输入层面）
bool bIsSprinting;    // 实际状态（物理层面）
```

分离"想不想冲刺"和"是否在冲刺"两个概念，便于后续扩展（比如耐力不足时 bWantsToSprint=true 但 bIsSprinting=false）。

### Tick 中切换速度

```cpp
void UBattleCharacterMovementComponent::TickComponent(float DeltaTime, ...) {
    Super::TickComponent(DeltaTime, TickType, ThisTickFunction);
    
    if (bWantsToSprint) {
        bIsSprinting = true;
        MaxWalkSpeed = SprintSpeed;  // 900
    } else {
        bIsSprinting = false;
        MaxWalkSpeed = WalkSpeed;   // 500
    }
}
```

**重要注释**：不受跳跃状态影响——空中也能切换速度值。这是有意设计，保持逻辑简单。

### 移动参数调优

| 参数 | 值 | 作用 |
|------|-----|------|
| MaxWalkSpeed | 500 / 900 | 行走/冲刺速度 |
| MaxAcceleration | 2048 | 加速度（越大起步越快） |
| GroundFriction | 8 | 地面摩擦力（越大停步越快） |
| BrakingDecelerationWalking | 2048 | 刹车减速度 |

**调参经验**：
- Acceleration 和 BrakingDeceleration 设为相同值（2048），保证加速和减速对称
- GroundFriction 较小（8），让角色有轻微滑动感，手感更流畅
- 冲刺速度 900 约等于行走速度的 1.8 倍，这个比例比较自然

## 经验总结

1. **替换默认组件必须在初始化列表**，使用 SetDefaultSubobjectClass<T>(ComponentName)
2. **速度切换放在 Tick 而不是 SetWantsToSprint 里**——保证每帧同步状态，避免边缘情况
3. **提供 IsSprinting() 常量查询方法**，供 AnimInstance 等其他系统读取
4. **后续可扩展**：加入耐力消耗、斜坡速度衰减、负重系统等

# 项目创建与目录结构

## 项目信息
- **项目名称**: ue5_battle（AIBattleDemo）
- **引擎版本**: UE5.7
- **开发工具**: VS2022 17.14 + Rider 2025.1.6
- **技术栈**: C++（不用蓝图编码）、GAS 5.7、MetaHuman、Meshy AI、ActorCore

## Build.cs 必须启用的模块

```cpp
PublicDependencyModuleNames.AddRange(new string[] {
    "Core",
    "CoreUObject", 
    "Engine",
    "InputCore",
    "GameplayAbilities",     // GAS 必需
    "GameplayTags",          // GAS 标签系统
    "GameplayTasks",         // GAS 任务系统
    "EnhancedInput",         // 增强输入系统
    "AIModule",              // AI 行为树
    "MetaHuman",             // MetaHuman 插件
    "MetaHumanRuntime"       // MetaHuman Runtime
});
```

## 经验总结

1. **构造函数中用 `static ConstructorHelpers::FObjectFinder` 加载资产**，避免每次构造都重新查找
2. **`SetDefaultSubobjectClass` 替换默认组件**：在构造函数初始化列表中替换 `ACharacter::CharacterMovementComponentName` 为自定义移动组件
3. **模型偏移调整**：`GetMesh()->SetRelativeLocation(FVector(0, 0, -90))` 让脚踩在胶囊体底部
4. **模型旋转修正**：`GetMesh()->SetRelativeRotation(FRotator(0, -90, 0))` 让角色面朝前方（UE 默认模型朝向是 X 轴，需要转 -90 度）
5. **弹簧臂长度 300** 是第三人称过肩视角的常用值

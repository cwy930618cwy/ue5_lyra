# AI 行为树设计

## 行为树结构

```
BT_EnemyBehavior
|
+-- Selector (Root)
    +-- 1. Blackboard: IsDead?
    |   +-- BTTask_Die (播放死亡动画)
    |
    +-- 2. Blackboard: IsStunned?
    |   +-- BTTask_Stun (眩晕等待)
    |
    +-- 3. Selector: Combat Decisions
    |   +-- Distance < 300? -> Melee Attack
    |   +-- Distance < 1000? -> Chase
    |   +-- IsRanged? -> Ranged Attack
    |
    +-- 4. Sequence: Patrol (默认)
        +-- GetNextPatrolPoint
        +-- MoveToPatrolPoint
        +-- WaitRandom(2~5s)
```

## 黑板 Key 设计

| Key 名称 | 类型 | 说明 |
|---------|------|------|
| IsDead | Bool | 是否死亡 |
| IsStunned | Bool | 是否眩晕 |
| TargetActor | Object | 当前目标 |
| DistanceToPlayer | Float | 到玩家的距离 |
| IsRanged | Bool | 是否远程敌人 |
| CurrentPatrolPoint | Vector | 当前巡逻点 |

## 敌人类型

| 类型 | 行为特点 | 属性倾向 |
|------|---------|---------|
| 近战兵 | 快速接近、连续攻击 | 低HP、高攻速 |
| 远程弓手 | 找掩体、保持距离射击 | 中HP、远程攻击 |
| 精英怪 | 多阶段、强力技能 | 高HP、多技能 |

# AI 资产生成工具链

## 教程使用的 AI 工具

| 工具 | 用途 | 网址 |
|------|------|------|
| Meshy AI | 文生/图生 3D 模型 | meshy.ai |
| MetaHuman | 高保真数字人创建 | metahuman.unrealengine.com |
| ActorCore | 动作捕捉动画库 | actorcore.reallusion.com |
| AudioLDM / Elevenlabs | AI 音效/语音生成 | - |

## 资产获取流程

```
Day 2: 策划文档 -> Meshy AI 生成武器/道具模型
Day 3: MetaHuman 创建主角 -> ActorCore 下载动画 -> Mixamo 补全
Day 6: 场景搭建 -> Quixel Megascans 填充环境
```

## 资产命名规范

```
T_前缀     → 纹理 (T_Hero_Diffuse)
SM_前缀    → 静态网格体 (SM_Rock_01)
SK_前缀    → 骨骼网格体 (SK_Hero)
ABP_前缀   → 动画蓝图 (ABP_Battle)
AM_前缀    → 攻击蒙太奇 (AM_MM_Rifle_Melee)
BT_前缀    → 行为树 (BT_EnemyBehavior)
BB_前缀    → 黑板 (BB_Enemy)
DA_前缀    → DataAsset (DA_BattleInputConfig)
IA_前缀    → InputAction (IA_Move)
IMC_前缀   → InputMappingContext (IMC_Default)
```

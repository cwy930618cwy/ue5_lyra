# 十九、插件系统（Plugins）

**路径**：`Plugins/`

## 内置插件（13个）
- `AsyncMixin` — 异步混入
- `CommonGame` — 通用游戏框架
- `CommonLoadingScreen` — 通用加载界面
- `CommonUser` — 通用用户系统
- `GameSettings` — 游戏设置
- `GameSubtitles` — 字幕系统
- `LyraExampleContent` — 示例内容
- `LyraExtTool` — Lyra 扩展工具
- `ModularGameplayActors` — 模块化 Gameplay Actor
- `PocketWorlds` — 口袋世界（快速加载小场景）
- `UIExtension` — UI 扩展
- `CommonUI` — CommonUI 框架集成
- `GameplayMessageRouter` — 消息路由

## GameFeature 插件（按需启用）
- `ShooterCore` — 射击核心
- `ShooterMaps` — 射击地图
- `ShooterExplorer` — 探索模式
- `TopDownArena` — 俯视角竞技场
- `ShooterTests` — 射击测试

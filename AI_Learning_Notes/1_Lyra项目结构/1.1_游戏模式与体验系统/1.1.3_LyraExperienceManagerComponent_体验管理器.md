# LyraExperienceManagerComponent — 体验管理器

## 它是谁？
挂在 `ALyraGameState` 上的一个 **GameStateComponent**，是整个 Experience 系统的核心调度器。它负责：
- 接收"加载这个 Experience"的指令
- 按顺序执行：加载资源 → 加载插件 → 执行 Action → 广播完成
- 管理整个生命周期状态

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraExperienceManagerComponent.h`
- 实现：`Source/LyraGame/GameModes/LyraExperienceManagerComponent.cpp`

## 继承关系
```
UActorComponent
  └── UGameStateComponent     ← 挂在 GameState 上，随 GameState 生命周期
        └── ULyraExperienceManagerComponent
              （同时实现 ILoadingProcessInterface）
```

## 核心接口（对外暴露的方法）

| 方法 | 用途 |
|------|------|
| `SetCurrentExperience(FPrimaryAssetId)` | 设置要加载的体验（入口方法） |
| `CallOrRegister_OnExperienceLoaded_HighPriority(Delegate)` | 注册高优先级回调（Experience 加载完立即调用） |
| `CallOrRegister_OnExperienceLoaded(Delegate)` | 注册普通优先级回调 |
| `CallOrRegister_OnExperienceLoaded_LowPriority(Delegate)` | 注册低优先级回调 |
| `GetCurrentExperienceChecked()` | 获取当前体验（要求已完全加载，否则 check 断言） |
| `IsExperienceLoaded()` | 查询是否已加载完毕 |
| `ShouldShowLoadingScreen(OutReason)` | ILoadingProcessInterface 实现，加载中返回 true |

## 三种优先级的回调

为什么要分三级？因为不同系统需要在不同时机初始化：

```
HighPriority（最先执行）
  └── 用于：子系统初始化、关键设置
Normal（第二执行）
  └── 用于：GameMode 生成 Pawn、常规游戏逻辑
LowPriority（最后执行）
  └── 用于：UI 刷新、非关键装饰
```

每个回调都是"如果已加载就立即执行，否则加入等待队列"的模式：
```cpp
void CallOrRegister_OnExperienceLoaded(FOnLyraExperienceLoaded::FDelegate&& Delegate)
{
    if (IsExperienceLoaded())
        Delegate.Execute(CurrentExperience);  // 已加载，立即执行
    else
        OnExperienceLoaded.Add(MoveTemp(Delegate));  // 未加载，排队等
}
```

## 内部状态变量

```cpp
private:
    // 当前体验（网络复制！服务器设置后同步到客户端）
    UPROPERTY(ReplicatedUsing=OnRep_CurrentExperience)
    TObjectPtr<const ULyraExperienceDefinition> CurrentExperience;

    // 加载状态
    ELyraExperienceLoadState LoadState = ELyraExperienceLoadState::Unloaded;

    // 正在加载的插件计数
    int32 NumGameFeaturePluginsLoading = 0;

    // 插件 URL 列表
    TArray<FString> GameFeaturePluginURLs;

    // 三级回调委托
    FOnLyraExperienceLoaded OnExperienceLoaded_HighPriority;
    FOnLyraExperienceLoaded OnExperienceLoaded;
    FOnLyraExperienceLoaded OnExperienceLoaded_LowPriority;
```

## 完整加载流程（源码级）

### Step 1: SetCurrentExperience()
```cpp
void SetCurrentExperience(FPrimaryAssetId ExperienceId)
{
    // 通过 AssetManager 把 PrimaryAssetId 转成实际对象
    ULyraAssetManager& AssetManager = ULyraAssetManager::Get();
    FSoftObjectPath AssetPath = AssetManager.GetPrimaryAssetPath(ExperienceId);
    TSubclassOf<ULyraExperienceDefinition> AssetClass = Cast<UClass>(AssetPath.TryLoad());
    const ULyraExperienceDefinition* Experience = GetDefault<ULyraExperienceDefinition>(AssetClass);

    CurrentExperience = Experience;
    StartExperienceLoad();  // 开始加载！
}
```

### Step 2: StartExperienceLoad()
```cpp
void StartExperienceLoad()
{
    LoadState = ELyraExperienceLoadState::Loading;

    // 收集要预加载的资产
    TSet<FPrimaryAssetId> BundleAssetList;
    BundleAssetList.Add(CurrentExperience->GetPrimaryAssetId());
    for (auto& ActionSet : CurrentExperience->ActionSets)
        BundleAssetList.Add(ActionSet->GetPrimaryAssetId());

    // 根据客户端/服务器决定加载哪个 Bundle
    TArray<FName> BundlesToLoad;
    BundlesToLoad.Add(FLyraBundles::Equipped);
    if (bLoadClient) BundlesToLoad.Add(LoadStateClient);
    if (bLoadServer) BundlesToLoad.Add(LoadStateServer);

    // 异步加载，完成后回调 OnExperienceLoadComplete
    Handle->BindCompleteDelegate(OnAssetsLoadedDelegate);
}
```

### Step 3: OnExperienceLoadComplete()
```cpp
void OnExperienceLoadComplete()
{
    LoadState = ELyraExperienceLoadState::LoadingGameFeatures;

    // 收集所有插件 URL（Experience 自己的 + ActionSets 的）
    CollectGameFeaturePluginURLs(CurrentExperience, CurrentExperience->GameFeaturesToEnable);
    for (auto& ActionSet : CurrentExperience->ActionSets)
        CollectGameFeaturePluginURLs(ActionSet, ActionSet->GameFeaturesToEnable);

    // 逐个加载并激活插件
    for (const FString& PluginURL : GameFeaturePluginURLs)
    {
        UGameFeaturesSubsystem::Get().LoadAndActivateGameFeaturePlugin(
            PluginURL,
            FGameFeaturePluginLoadComplete::CreateUObject(this, &ThisClass::OnGameFeaturePluginLoadComplete)
        );
    }
}
```

### Step 4: OnExperienceFullLoadCompleted()
```cpp
void OnExperienceFullLoadCompleted()
{
    LoadState = ELyraExperienceLoadState::ExecutingActions;

    // 执行所有 Action（Experience 自己的 + ActionSets 的）
    ActivateListOfActions(CurrentExperience->Actions);
    for (auto& ActionSet : CurrentExperience->ActionSets)
        ActivateListOfActions(ActionSet->Actions);

    LoadState = ELyraExperienceLoadState::Loaded;

    // 广播三级回调
    OnExperienceLoaded_HighPriority.Broadcast(CurrentExperience);
    OnExperienceLoaded.Broadcast(CurrentExperience);
    OnExperienceLoaded_LowPriority.Broadcast(CurrentExperience);
}
```

## Action 的生命周期回调
每个 `UGameFeatureAction` 会收到三个激活回调：
```cpp
Action->OnGameFeatureRegistering();   // 注册
Action->OnGameFeatureLoading();       // 加载
Action->OnGameFeatureActivating(Context);  // 激活（传入世界上下文）
```

## 网络复制
- `CurrentExperience` 标记了 `ReplicatedUsing=OnRep_CurrentExperience`
- 服务器设置 Experience 后，客户端自动收到通知
- 客户端收到后也调用 `StartExperienceLoad()` 开始本地加载

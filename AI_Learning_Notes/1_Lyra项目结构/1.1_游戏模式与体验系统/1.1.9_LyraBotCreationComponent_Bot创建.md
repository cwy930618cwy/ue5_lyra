# LyraBotCreationComponent — Bot 创建组件

## 它是谁？
`ULyraBotCreationComponent` 是一个挂在 GameState 上的组件，负责在游戏开始时自动创建 AI 机器人（Bot）。

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraBotCreationComponent.h`
- 实现：`Source/LyraGame/GameModes/LyraBotCreationComponent.cpp`

## 继承关系
```
UActorComponent
  └── UGameStateComponent
        └── ULyraBotCreationComponent
```

## 核心配置字段

```cpp
protected:
    // 要创建的 Bot 数量
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Gameplay)
    int32 NumBotsToCreate = 5;

    // Bot 控制器类
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Gameplay)
    TSubclassOf<AAIController> BotControllerClass;

    // 随机 Bot 名字池
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category=Gameplay)
    TArray<FString> RandomBotNames;
```

## 运行时状态
```cpp
    // 剩余可用的名字
    TArray<FString> RemainingBotNames;

    // 已生成的 Bot 列表
    UPROPERTY(Transient)
    TArray<TObjectPtr<AAIController>> SpawnedBotList;
```

## 核心方法

| 方法 | 权限 | 用途 |
|------|------|------|
| `SpawnOneBot()` | BlueprintAuthorityOnly | 生成一个 Bot |
| `RemoveOneBot()` | BlueprintAuthorityOnly | 移除最后一个 Bot |
| `ServerCreateBots()` | BlueprintNativeEvent | 批量创建（子类可覆写） |
| `Cheat_AddBot()` | 仅服务器代码 | 作弊命令：加一个 Bot |
| `Cheat_RemoveBot()` | 仅服务器代码 | 作弊命令：减一个 Bot |

## 工作流程
```
BeginPlay
  ↓
监听 ExperienceManagerComponent 的 OnExperienceLoaded
  ↓
Experience 加载完成
  ↓
ServerCreateBots()（BlueprintNativeEvent，可在蓝图中覆写）
  ↓
循环 NumBotsToCreate 次，调用 SpawnOneBot()
  ↓
每个 Bot：
  ├── 从 RandomBotNames 中随机取一个名字
  ├── 生成 AIController
  └── 生成 Pawn 并 Possess
```

## 设计要点
- **Blueprintable, Abstract**：这是一个抽象基类，需要在蓝图中创建具体子类
- **服务器权威**：所有生成/移除操作都标记了 `BlueprintAuthorityOnly`，只在服务器执行
- **名字池机制**：用 `RemainingBotNames` 数组管理可用名字，避免重名
- **作弊支持**：内置 `Cheat_AddBot/RemoveBot`，方便开发调试

## 在你项目中的参考意义
如果你要做单人游戏 + AI 敌人，可以参考这个组件的模式：
1. 组件挂在 GameState 上
2. 监听 Experience/游戏就绪事件
3. 在指定位置生成 AI 角色
4. 用名字池给 AI 取名

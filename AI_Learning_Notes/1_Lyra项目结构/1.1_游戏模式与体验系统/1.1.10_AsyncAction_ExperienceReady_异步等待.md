# AsyncAction_ExperienceReady — 异步等待 Experience 就绪

## 它是谁？
`UAsyncAction_ExperienceReady` 是一个 **蓝图异步动作**，让蓝图开发者可以优雅地等待 Experience 加载完成后再执行后续逻辑。

## 文件位置
- 头文件：`Source/LyraGame/GameModes/AsyncAction_ExperienceReady.h`
- 实现：`Source/LyraGame/GameModes/AsyncAction_ExperienceReady.cpp`

## 继承关系
```
UBlueprintAsyncActionBase
  └── UAsyncAction_ExperienceReady
```

## 使用方法（蓝图中）
```
Wait For Experience Ready
    └── On Ready → 执行后续逻辑
```

## 核心接口

```cpp
UFUNCTION(BlueprintCallable, meta=(WorldContext = "WorldContextObject"))
static UAsyncAction_ExperienceReady* WaitForExperienceReady(UObject* WorldContextObject);

// 完成回调
UPROPERTY(BlueprintAssignable)
FExperienceReadyAsyncDelegate OnReady;
```

## 内部实现步骤（4步）

```cpp
private:
    void Step1_HandleGameStateSet(AGameStateBase* GameState);
    void Step2_ListenToExperienceLoading(AGameStateBase* GameState);
    void Step3_HandleExperienceLoaded(const ULyraExperienceDefinition* CurrentExperience);
    void Step4_BroadcastReady();
```

### Step 1: 获取 GameState
- 从 WorldContextObject 拿到 World
- 从 World 拿到 GameState

### Step 2: 监听 Experience 加载
- 找到 GameState 上的 ExperienceManagerComponent
- 注册 OnExperienceLoaded 回调

### Step 3: Experience 加载完成
- 收到回调，确认 Experience 已就绪

### Step 4: 广播 OnReady
- 触发蓝图中的 OnReady 事件
- 销毁自身（AsyncAction 是一次性的）

## 容错设计
- 如果 GameState 已经存在且 Experience 已加载，**立即调用 OnReady**（不等待）
- 如果 GameState 还不存在，会监听 GameState 的创建

## 在蓝图中的典型用法
```
Event BeginPlay
  → WaitForExperienceReady
      → On Ready:
          → 初始化 UI
          → 显示游戏模式选择
          → 或其他需要等 Experience 就绪的逻辑
```

## 为什么需要它？
Experience 是异步加载的，如果在 Experience 没准备好时就执行某些逻辑（比如生成 Pawn、初始化 UI），可能会因为数据不存在而崩溃。这个 AsyncAction 提供了一个安全的等待机制。

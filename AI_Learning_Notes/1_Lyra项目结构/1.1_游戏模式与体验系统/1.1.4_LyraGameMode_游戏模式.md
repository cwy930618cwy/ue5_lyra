# LyraGameMode — 游戏模式

## 它是谁？
`ALyraGameMode` 是 Lyra 的游戏模式基类，继承自 `AModularGameModeBase`。它负责：
- 确定使用哪个 Experience
- 玩家/Bot 的登录、出生、复活
- 与 ExperienceManagerComponent 协作

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraGameMode.h`
- 实现：`Source/LyraGame/GameModes/LyraGameMode.cpp`

## 继承关系
```
AGameModeBase
  └── AModularGameModeBase    ← 支持组件化（Modular Gameplay）
        └── ALyraGameMode
```

**要点**：所有关键类的默认值都在这里指定，但 Pawn 的实际类型会被 Experience 覆盖。

## 核心职责一：确定 Experience（Experience 选择逻辑）

`HandleMatchAssignmentIfNotExpectingOne()` 按以下优先级决定用哪个 Experience：

```
优先级从高到低：
1. Matchmaking 分配（在线匹配）
2. URL Options 参数（?Experience=xxx）
3. Developer Settings（仅 PIE 模式）
4. 命令行参数（-Experience=xxx）
5. WorldSettings 里的默认值
6. 专用服务器自动托管
7. 最终 fallback：B_LyraDefaultExperience
```

```cpp
void ALyraGameMode::HandleMatchAssignmentIfNotExpectingOne()
{
    // InitGame 的下一帧执行
    // 按优先级逐级检查...
    
    // 最终 fallback
    if (!ExperienceId.IsValid())
    {
        ExperienceId = FPrimaryAssetId(
            FPrimaryAssetType("LyraExperienceDefinition"),
            FName("B_LyraDefaultExperience")
        );
    }
    
    OnMatchAssignmentGiven(ExperienceId, ExperienceIdSource);
}
```

## 核心职责二：玩家 Pawn 生成

### GetDefaultPawnClassForController — 动态决定 Pawn 类型
```cpp
UClass* ALyraGameMode::GetDefaultPawnClassForController_Implementation(AController* InController)
{
    // 先尝试从 PlayerState 拿 PawnData
    if (const ULyraPawnData* PawnData = GetPawnDataForController(InController))
    {
        if (PawnData->PawnClass)
            return PawnData->PawnClass;  // 用 Experience 配置的 Pawn 类型！
    }
    return Super::GetDefaultPawnClassForController_Implementation(InController);
}
```

### SpawnDefaultPawnAtTransform — 生成 Pawn 并设置 PawnData
```cpp
APawn* ALyraGameMode::SpawnDefaultPawnAtTransform_Implementation(
    AController* NewPlayer, const FTransform& SpawnTransform)
{
    UClass* PawnClass = GetDefaultPawnClassForController(NewPlayer);
    APawn* SpawnedPawn = GetWorld()->SpawnActor<APawn>(PawnClass, SpawnTransform, SpawnInfo);

    // 关键：把 PawnData 设置到 PawnExtensionComponent
    if (ULyraPawnExtensionComponent* PawnExtComp = 
        ULyraPawnExtensionComponent::FindPawnExtensionComponent(SpawnedPawn))
    {
        PawnExtComp->SetPawnData(GetPawnDataForController(NewPlayer));
    }

    SpawnedPawn->FinishSpawning(SpawnTransform);
    return SpawnedPawn;
}
```

void ALyraGameMode::HandleStartingNewPlayer_Implementation(APlayerController* NewPlayer)

## GetPawnDataForController — PawnData 获取链
```cpp
const ULyraPawnData* ALyraGameMode::GetPawnDataForController(const AController* InController) const
{
    // 1. 先看 PlayerState 上有没有（已被赋值过）
    if (const ALyraPlayerState* LyraPS = InController->GetPlayerState<ALyraPlayerState>())
        if (const ULyraPawnData* PawnData = LyraPS->GetPawnData<ULyraPawnData>())
            return PawnData;

    // 2. 看 Experience 是否加载完
    ULyraExperienceManagerComponent* ExperienceComponent = 
        GameState->FindComponentByClass<ULyraExperienceManagerComponent>();
    if (ExperienceComponent->IsExperienceLoaded())
    {
        const ULyraExperienceDefinition* Experience = ExperienceComponent->GetCurrentExperienceChecked();
        if (Experience->DefaultPawnData != nullptr)
            return Experience->DefaultPawnData;

        // 3. Experience 没有配置，用全局默认
        return ULyraAssetManager::Get().GetDefaultPawnData();
    }

    // 4. Experience 还没加载完，返回空
    return nullptr;
}
```

## 关键设计总结

| 设计点 | 说明 |
|--------|------|
| ModularGameModeBase | 支持组件化扩展，可以在 GameMode 上挂组件 |
| Experience 驱动 Pawn | Pawn 类型不是硬编码的，由 Experience → PawnData → PawnClass 决定 |
| 延迟生成 | 等 Experience 加载完才生成 Pawn，确保数据就绪 |
| 委托监听 | InitGameState 时注册 OnExperienceLoaded 回调 |
| ShouldSpawnAtStartSpot = false | 不使用引擎默认的出生点，完全由 PlayerSpawningManagerComponent 管理 |

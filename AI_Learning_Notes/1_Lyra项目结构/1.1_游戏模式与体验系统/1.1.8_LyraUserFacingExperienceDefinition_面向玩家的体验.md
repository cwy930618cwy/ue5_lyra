# LyraUserFacingExperienceDefinition — 面向玩家的体验定义

## 它是谁？
`ULyraUserFacingExperienceDefinition` 是一个 **面向主菜单/UI 的体验定义**。它不仅包含"玩什么"的信息，还包含"怎么展示"的 UI 信息。

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraUserFacingExperienceDefinition.h`
- 实现：`Source/LyraGame/GameModes/LyraUserFacingExperienceDefinition.cpp`

## 继承关系
```
UObject
  └── UDataAsset
        └── UPrimaryDataAsset
              └── ULyraUserFacingExperienceDefinition
```

## 与 ExperienceDefinition 的区别

| 特性 | LyraExperienceDefinition | LyraUserFacingExperienceDefinition |
|------|--------------------------|-----------------------------------|
| 用途 | 游戏逻辑配置 | 主菜单/UI 展示 |
| 使用者 | 程序员/策划 | 策划 + UI |
| 内容 | GameFeature、Pawn、Actions | 地图、标题、图标、描述 |
| 关系 | 被引用 | 引用 ExperienceDefinition |

简单说：**UserFacing 是给玩家看的"封面"，Experience 是给程序用的"内核"**。

## 核心字段

```cpp
UCLASS(BlueprintType)
class ULyraUserFacingExperienceDefinition : public UPrimaryDataAsset
{
public:
    // === 游戏配置 ===
    
    /** 要加载的地图 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience, 
              meta=(AllowedTypes="Map"))
    FPrimaryAssetId MapID;

    /** 要加载的游戏体验 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience, 
              meta=(AllowedTypes="LyraExperienceDefinition"))
    FPrimaryAssetId ExperienceID;

    /** 额外的 URL 参数 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    TMap<FString, FString> ExtraArgs;

    // === UI 展示 ===
    
    /** 主标题 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    FText TileTitle;

    /** 副标题 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    FText TileSubTitle;

    /** 完整描述 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    FText TileDescription;

    /** 图标 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    TObjectPtr<UTexture2D> TileIcon;

    // === 加载界面 ===
    
    /** 加载界面 Widget */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=LoadingScreen)
    TSoftClassPtr<UUserWidget> LoadingScreenWidget;

    // === 其他设置 ===
    
    /** 是否为默认体验（快速开始用） */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    bool bIsDefaultExperience = false;

    /** 是否在前端列表中显示 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    bool bShowInFrontEnd = true;

    /** 是否录制回放 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    bool bRecordReplay = false;

    /** 最大玩家数 */
    UPROPERTY(BlueprintReadWrite, EditAnywhere, Category=Experience)
    int32 MaxPlayerCount = 16;
};
```

## 典型使用场景

1. **主菜单**：遍历所有 `LyraUserFacingExperienceDefinition` 资产，显示为游戏模式卡片
2. **专用服务器**：通过 `-UserExperience=` 命令行参数指定要托管的模式
3. **快速开始**：找到 `bIsDefaultExperience = true` 的那个，直接进入

## 数据流
```
主菜单 UI
  ↓ 玩家选择了一个模式
ULyraUserFacingExperienceDefinition
  ├── MapID → 加载对应地图
  ├── ExperienceID → 加载对应的 LyraExperienceDefinition
  ├── ExtraArgs → 附加参数传给 GameMode
  └── LoadingScreenWidget → 显示加载界面
```

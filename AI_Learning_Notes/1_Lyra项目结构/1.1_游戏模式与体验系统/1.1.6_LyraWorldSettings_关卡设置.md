# LyraWorldSettings — 关卡设置

## 它是谁？
`ALyraWorldSettings` 是 Lyra 的世界设置类，继承自 `AWorldSettings`。它的作用很简单：**在关卡层面指定默认使用哪个 Experience**。

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraWorldSettings.h`
- 实现：`Source/LyraGame/GameModes/LyraWorldSettings.cpp`

## 继承关系
```
AWorldSettings
  └── ALyraWorldSettings
```

## 核心字段

```cpp
protected:
    // 这张地图默认使用的 Experience
    // 使用 TSoftClassPtr 软引用，避免强制加载
    UPROPERTY(EditDefaultsOnly, Category = GameMode)
    TSoftClassPtr<ULyraExperienceDefinition> DefaultGameplayExperience;

#if WITH_EDITORONLY_DATA
    // 是否在编辑器 Play 时强制 Standalone 模式
    UPROPERTY(EditDefaultsOnly, Category = PIE)
    bool ForceStandaloneNetMode = false;
#endif
```

## 关键方法

```cpp
// 获取默认 Experience 的 PrimaryAssetId
FPrimaryAssetId GetDefaultGameplayExperience() const;
```

## 在 Experience 选择中的位置

回顾 `ALyraGameMode::HandleMatchAssignmentIfNotExpectingOne()` 的优先级：

```
1. Matchmaking 分配        ← 最高
2. URL Options 参数
3. Developer Settings (PIE)
4. 命令行参数
5. WorldSettings 默认值    ← 就在这里！
6. 专用服务器
7. 最终 fallback           ← 最低
```

所以 WorldSettings 是第 5 优先级。如果上面都没指定，就用这里配置的。

## 如何使用
1. 打开关卡
2. 在 World Outliner 中找到 WorldSettings
3. 在 Details 面板的 GameMode 分类下找到 `Default Gameplay Experience`
4. 选择你要用的 Experience 数据资产

## 设计要点
- **软引用（TSoftClassPtr）**：不会在关卡加载时强制加载 Experience，避免不必要的资源消耗
- **编辑器专用字段**：`ForceStandaloneNetMode` 只在编辑器可见，不影响打包后的游戏

# LyraExperienceDefinition — 体验定义

## 它是谁？
`ULyraExperienceDefinition` 是一个 **PrimaryDataAsset**，相当于一份"游戏模式配置文件"。策划在编辑器里右键创建一个实例，填好参数，就定义了一种玩法。

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraExperienceDefinition.h`
- 实现：`Source/LyraGame/GameModes/LyraExperienceDefinition.cpp`

## 继承关系
```
UObject
  └── UDataAsset
        └── UPrimaryDataAsset     ← 可以被 AssetManager 管理、支持 Bundle 加载
              └── ULyraExperienceDefinition
```

## 核心字段（就 4 个，全是配置项）

```cpp
UCLASS(BlueprintType, Const)
class ULyraExperienceDefinition : public UPrimaryDataAsset
{
public:
    // ① 要启用的 GameFeature 插件列表
    UPROPERTY(EditDefaultsOnly, Category = Gameplay)
    TArray<FString> GameFeaturesToEnable;

    // ② 默认 Pawn 数据（玩家用什么角色）
    UPROPERTY(EditDefaultsOnly, Category = Gameplay)
    TObjectPtr<const ULyraPawnData> DefaultPawnData;

    // ③ 直接定义的 Action 列表（内联）
    UPROPERTY(EditDefaultsOnly, Instanced, Category = "Actions")
    TArray<TObjectPtr<UGameFeatureAction>> Actions;

    // ④ 引用的 ActionSet（复用其他定义好的 Action 组合）
    UPROPERTY(EditDefaultsOnly, Category = Gameplay)
    TArray<TObjectPtr<ULyraExperienceActionSet>> ActionSets;
};
```

## 逐字段详解

### ① GameFeaturesToEnable
- **类型**：`TArray<FString>`
- **含义**：这局游戏需要启用哪些 GameFeature 插件
- **示例值**：`["ShooterCore", "ShooterMaps"]`
- **原理**：ExperienceManagerComponent 会根据这些名字查找插件 URL，然后调用 `LoadAndActivateGameFeaturePlugin()`

### ② DefaultPawnData
- **类型**：`TObjectPtr<const ULyraPawnData>`
- **含义**：玩家默认使用什么 Pawn（角色配置）
- **注意**：这是 const 指针，说明 Experience 不修改 PawnData，只读取
- **为空时**：fallback 到 `ULyraAssetManager::GetDefaultPawnData()`

### ③ Actions（内联）
- **类型**：`TArray<TObjectPtr<UGameFeatureAction>>`
- **Instanced**：表示这些 Action 是 Experience 的内联子对象（不是外部引用）
- **含义**：直接在 Experience 里定义要执行的 Action

### ④ ActionSets（引用）
- **类型**：`TArray<TObjectPtr<ULyraExperienceActionSet>>`
- **含义**：引用外部的 ActionSet 数据资产，实现复用
- **典型场景**：多个 Experience 共享同一组"基础 UI Action"

## 在编辑器中如何创建？
1. Content Browser 右键 → Miscellaneous → Data Asset
2. 选择 `LyraExperienceDefinition` 作为父类
3. 命名（如 `DA_ShooterExperience`）
4. 填写 4 个字段

## 蓝图中的使用
- 标记了 `BlueprintType, Const`，蓝图中可以读取但不能修改
- 通过 `ULyraExperienceManagerComponent::GetCurrentExperienceChecked()` 获取当前实例

## 关键设计点
1. **PrimaryDataAsset**：支持 AssetManager 的 Bundle 系统，可以按平台/角色分别加载不同资源
2. **Const**：运行时不可修改，保证配置一致性
3. **Actions + ActionSets 分离**：内联 vs 复用，灵活组合

---

> 📂 相关类：`ULyraExperienceActionSet`（Action 集合）、`ULyraPawnData`（Pawn 数据）

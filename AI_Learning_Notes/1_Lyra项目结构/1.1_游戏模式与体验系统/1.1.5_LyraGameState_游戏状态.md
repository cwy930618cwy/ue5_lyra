# LyraGameState — 游戏状态

## 它是谁？
`ALyraGameState` 是 Lyra 的游戏状态基类，继承自 `AModularGameStateBase`。它负责：
- 作为 ExperienceManagerComponent 的宿主
- 提供 GameState 级别的全局 ASC（AbilitySystemComponent）
- 管理玩家状态的增删
- 向所有客户端广播消息

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraGameState.h`
- 实现：`Source/LyraGame/GameModes/LyraGameState.cpp`

## 继承关系
```
AGameStateBase
  └── AModularGameStateBase    ← 支持组件化
        └── ALyraGameState
              └── 同时实现 IAbilitySystemInterface
```

## 核心组件

### ExperienceManagerComponent（最重要的成员）
```cpp
private:
    UPROPERTY()
    TObjectPtr<ULyraExperienceManagerComponent> ExperienceManagerComponent;
```
- 在编辑器中作为子对象添加到 GameState
- 负责加载和管理当前 Experience

### 全局 AbilitySystemComponent
```cpp
UPROPERTY(VisibleAnywhere, Category = "Lyra|GameState")
TObjectPtr<ULyraAbilitySystemComponent> AbilitySystemComponent;
```
- GameState 级别的 ASC，用于全局 GameplayCue 等
- 通过 `IAbilitySystemInterface::GetAbilitySystemComponent()` 暴露

## 核心接口

| 方法 | 用途 |
|------|------|
| `GetLyraAbilitySystemComponent()` | 获取全局 ASC（蓝图可调用） |
| `MulticastMessageToClients(Message)` | 广播消息给所有客户端（不可靠，用于击杀提示等） |
| `MulticastReliableMessageToClients(Message)` | 广播消息给所有客户端（可靠，用于不能丢失的通知） |
| `GetServerFPS()` | 获取服务器帧率（复制给客户端显示） |
| `SetRecorderPlayerState(NewPS)` | 设置回放录制者 |
| `GetRecorderPlayerState()` | 获取回放录制者 |

## 消息广播系统
```cpp
// 不可靠消息（可能丢失，用于非关键通知）
UFUNCTION(NetMulticast, Unreliable, BlueprintCallable)
void MulticastMessageToClients(const FLyraVerbMessage Message);

// 可靠消息（保证送达，用于关键通知）
UFUNCTION(NetMulticast, Reliable, BlueprintCallable)
void MulticastReliableMessageToClients(const FLyraVerbMessage Message);
```

## 玩家状态管理
```cpp
virtual void AddPlayerState(APlayerState* PlayerState) override;
virtual void RemovePlayerState(APlayerState* PlayerState) override;
virtual void SeamlessTravelTransitionCheckpoint(bool bToTransitionMap) override;
```
重写这三个方法是为了在玩家加入/离开/无缝切换时做额外处理。

## 生命周期
```cpp
virtual void PreInitializeComponents() override;   // 组件初始化前
virtual void PostInitializeComponents() override;  // 组件初始化后
virtual void EndPlay(const EEndPlayReason::Type) override;  // 结束游戏
virtual void Tick(float DeltaSeconds) override;    // 每帧更新（用于统计 FPS）
```

## 网络复制属性
```cpp
protected:
    UPROPERTY(Replicated)
    float ServerFPS;  // 服务器帧率，复制给客户端

    UPROPERTY(Transient, ReplicatedUsing = OnRep_RecorderPlayerState)
    TObjectPtr<APlayerState> RecorderPlayerState;  // 回放录制者
```

## 在你项目中的参考意义

如果你要做单机游戏，不需要 GameState 级别的 ASC 和网络复制。但你可能会用到：
- **ExperienceManagerComponent 的回调机制**：如何在某个系统就绪后通知其他系统
- **消息广播模式**：如何向所有客户端发送通知

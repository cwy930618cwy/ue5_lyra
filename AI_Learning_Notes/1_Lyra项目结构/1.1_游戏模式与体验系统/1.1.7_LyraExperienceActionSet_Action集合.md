# LyraExperienceActionSet — Action 集合

## 它是谁？
`ULyraExperienceActionSet` 是一个 **可复用的 Action 组合包**。多个 Experience 可以引用同一个 ActionSet，避免重复配置。

## 文件位置
- 头文件：`Source/LyraGame/GameModes/LyraExperienceActionSet.h`
- 实现：`Source/LyraGame/GameModes/LyraExperienceActionSet.cpp`

## 继承关系
```
UObject
  └── UDataAsset
        └── UPrimaryDataAsset
              └── ULyraExperienceActionSet
```

## 核心字段（只有 2 个）

```cpp
UCLASS(BlueprintType, NotBlueprintable)
class ULyraExperienceActionSet : public UPrimaryDataAsset
{
public:
    // Action 列表
    UPROPERTY(EditAnywhere, Instanced, Category = "Actions to Perform")
    TArray<TObjectPtr<UGameFeatureAction>> Actions;

    // 这些 Action 依赖的 GameFeature 插件
    UPROPERTY(EditAnywhere, Category = "Feature Dependencies")
    TArray<FString> GameFeaturesToEnable;
};
```

## 与 ExperienceDefinition 的关系

```
ULyraExperienceDefinition
  ├── Actions（内联，直接定义）
  └── ActionSets（引用，指向外部的 ActionSet 资产）
        ├── ActionSet_A（有自己的 Actions + GameFeaturesToEnable）
        ├── ActionSet_B
        └── ...
```

**为什么要分开？**
- Experience 的 `Actions`：专属于这个 Experience 的 Action
- Experience 的 `ActionSets`：多个 Experience 共享的通用 Action 组合

**典型场景**：
- `ActionSet_CommonUI`：所有 Experience 都需要的 UI 初始化 Action
- `ActionSet_AudioSetup`：所有 Experience 都需要的音频设置 Action
- 射击模式额外加 `ActionSet_Weapons`
- 探索模式额外加 `ActionSet_Exploration`

## 在加载流程中的作用

`ExperienceManagerComponent` 会把 Experience 和它引用的所有 ActionSet 的 Action **合并执行**：

```cpp
// 先执行 Experience 自己的 Actions
ActivateListOfActions(CurrentExperience->Actions);

// 再执行每个 ActionSet 的 Actions
for (const TObjectPtr<ULyraExperienceActionSet>& ActionSet : CurrentExperience->ActionSets)
{
    if (ActionSet != nullptr)
        ActivateListOfActions(ActionSet->Actions);
}
```

同样，GameFeature 插件也会合并加载：
```cpp
CollectGameFeaturePluginURLs(CurrentExperience, CurrentExperience->GameFeaturesToEnable);
for (auto& ActionSet : CurrentExperience->ActionSets)
    CollectGameFeaturePluginURLs(ActionSet, ActionSet->GameFeaturesToEnable);
```

## 设计要点
- **NotBlueprintable**：不能在蓝图中创建子类，只能通过数据资产配置
- **Instanced Actions**：Action 是 ActionSet 的内联子对象
- **组合优于继承**：通过引用不同的 ActionSet 来组合行为，而不是写不同的 Experience 子类

---

> 📂 关联：`ULyraExperienceDefinition`（引用者）、`UGameFeatureAction`（Action 基类）

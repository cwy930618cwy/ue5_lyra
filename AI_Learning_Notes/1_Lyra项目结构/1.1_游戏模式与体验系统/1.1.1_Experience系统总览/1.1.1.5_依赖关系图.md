# 依赖关系图

## 类之间的依赖

```
ALyraGameMode
  ├── 依赖 ALyraGameState（构造函数里指定 GameStateClass）
  ├── 依赖 ULyraExperienceManagerComponent（从 GameState 上 FindComponentByClass）
  ├── 依赖 ULyraExperienceDefinition（通过 AssetManager 加载）
  └── 依赖 ULyraPawnData（从 Experience 里拿 DefaultPawnData）

ALyraGameState
  ├── 持有 ULyraExperienceManagerComponent（CreateDefaultSubobject）
  └── 实现 IAbilitySystemInterface（提供全局 ASC）

ULyraExperienceDefinition（DataAsset，策划在编辑器里配）
  ├── TArray<FString> GameFeaturesToEnable    ← 要启用的插件名列表
  ├── TObjectPtr<ULyraPawnData> DefaultPawnData ← 默认 Pawn 数据
  ├── TArray<UGameFeatureAction*> Actions      ← 内联 Action 列表
  └── TArray<ULyraExperienceActionSet*> ActionSets ← 引用的 ActionSet
```

## 生命周期依赖

```
引擎启动
  ↓
ALyraGameMode 创建（指定 GameStateClass、GameSessionClass 等）
  ↓
ALyraGameState 创建（包含 ExperienceManagerComponent）
  ↓
ALyraGameMode::InitGame()
  ↓
下一帧：HandleMatchAssignmentIfNotExpectingOne()
  ↓
OnMatchAssignmentGiven() → ExperienceManagerComponent::SetCurrentExperience()
  ↓
ExperienceManagerComponent 开始异步加载
  ↓
加载完成 → 执行 Action → 广播 OnExperienceLoaded
  ↓
ALyraGameMode::OnExperienceLoaded() → 生成 Pawn
```

## 数据流向

```
策划配置                    运行时加载                   游戏使用
─────────                  ──────────                  ──────────
ExperienceDefinition  →  AssetManager 加载  →  ExperienceManagerComponent
      ↓                                              ↓
  PawnData            →  GameMode 读取      →  SpawnDefaultPawnAtTransform
      ↓                                              ↓
  GameFeature 列表     →  Subsystem 加载     →  Action 执行
      ↓                                              ↓
  Actions             →  逐个激活           →  游戏逻辑初始化
```

## 对你项目的参考

你的 `ue5_lyra` 目前不需要完整的 Experience 系统，但可以借鉴：
1. **数据驱动思想**：用 DataAsset 配置参数
2. **组件化设计**：功能拆分到独立 Component
3. **异步加载 + 回调**：避免卡顿，确保数据就绪后再执行

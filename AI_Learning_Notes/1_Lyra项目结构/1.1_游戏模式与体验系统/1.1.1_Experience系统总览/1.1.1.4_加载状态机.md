# 加载状态机

## 状态转换图

```
Unloaded ──→ Loading ──→ LoadingGameFeatures ──→ ExecutingActions ──→ Loaded
                                                              ↑            │
                                                              │            ↓
                                                    (可选chaos延迟)   Deactivating ──→ Unloaded
```

## 枚举定义

源码位置：`LyraExperienceManagerComponent.h`

```cpp
enum class ELyraExperienceLoadState
{
    Unloaded,               // 未加载（初始状态）
    Loading,                // 正在加载资源 Bundle
    LoadingGameFeatures,    // 正在加载 GameFeature 插件
    LoadingChaosTestingDelay, // 混沌测试延迟（调试用）
    ExecutingActions,       // 正在执行 Action
    Loaded,                 // 完全加载完毕（终态）
    Deactivating            // 正在卸载（回到 Unloaded）
};
```

## 各状态含义

| 状态 | 触发条件 | 做什么 |
|------|----------|--------|
| `Unloaded` | 初始状态 / 卸载完成 | 无 |
| `Loading` | 调用 `StartExperienceLoad()` | 异步加载 Experience + ActionSets 的资源 |
| `LoadingGameFeatures` | 资源加载完成 | 加载并激活 GameFeature 插件 |
| `LoadingChaosTestingDelay` | 插件加载完成 | 随机延迟（模拟网络波动，仅调试） |
| `ExecutingActions` | 延迟结束（或跳过） | 执行所有 Action 的生命周期回调 |
| `Loaded` | Action 执行完成 | 广播回调，标记就绪 |
| `Deactivating` | 调用卸载 | 反向执行 Action 的 Deactivate/Unload |

## 状态查询接口

```cpp
// ExperienceManagerComponent 提供
ELyraExperienceLoadState GetLoadState() const;
bool IsExperienceLoaded() const;  // 判断是否 == Loaded
```

## Chaos Testing（混沌测试）

控制台变量：
```
lyra.chaos.ExperienceDelayLoad.MinSecs    # 最小延迟秒数（默认 0）
lyra.chaos.ExperienceDelayLoad.RandomSecs # 随机延迟范围（默认 0）
```

开启后会在 `LoadingGameFeatures` 和 `ExecutingActions` 之间插入随机延迟，用于测试加载界面的表现。

# 完整工作流程时间线

## 一个场景引入

前两步我们知道了 Experience 是什么、有哪些文件。但你可能还是不清楚：

> "游戏启动后，这些文件是怎么一步步协作的？从玩家双击图标到角色出现在屏幕上，中间发生了什么？"

这篇按时间顺序，把整个流程拆成 **8 个步骤**，每一步告诉你：谁在做什么、为什么这么做、关键代码在哪。

---

## 核心思想

> **一条异步加载链：GameMode 发起 → Component 调度 → Manager 执行 → Action 激活 → Pawn 生成**

---

## 8 步完整流程

### 第 1 步：引擎创建 GameMode 和 GameState

**时机**：游戏启动，加载第一个关卡时

```cpp
// 引擎自动创建（不需要手动写）：
// - ALyraGameMode（读取项目设置的 DefaultGameMode）
// - ALyraGameState（GameMode 的对应 State）
//   └── 自动带上 ULyraExperienceManagerComponent（因为 GameState 里声明了）
```

**关键点**：`ExperienceManagerComponent` 是挂在 `GameState` 上的，不是 `GameMode` 上。因为 GameState 在客户端也存在，而 GameMode 只在服务器。

---

### 第 2 步：`InitGame()` — 触发加载

**时机**：GameMode 初始化完成

```cpp
void ALyraGameMode::InitGame(const FURL& URL, UGameInstance* GameInstance)
{
	Super::InitGame(URL, GameInstance);
	HandleMatchAssignmentIfNotExpectingOne();  // 触发 Experience 加载
}
```

**关键点**：`InitGame` 是 UE5 GameMode 的生命周期入口，比 `BeginPlay` 更早调用。

> 📄 完整实现见 `代码/LyraGameMode.cpp`

---

### 第 3 步：`HandleMatchAssignmentIfNotExpectingOne()` — 确定用哪个 Experience

**时机**：`InitGame` 内部调用

```cpp
void ALyraGameMode::HandleMatchAssignmentIfNotExpectingOne()
{
	if (CurrentExperience) return;  // 已加载则跳过

	ALyraGameState* GameState = GetGameState<ALyraGameState>();
	ULyraExperienceManagerComponent* Component = 
		GameState->FindComponentByClass<ULyraExperienceManagerComponent>();

	// 委托给 Component 异步加载
	Component->SetCurrentExperience(FPrimaryAssetId());
}
```

**优先级链**：

```
WorldSettings.DefaultGameplayExperience  ← 最高优先（关卡级覆盖）
        ↓ 如果没有
命令行参数 -Experience=xxx                ← 调试用
        ↓ 如果没有
项目设置 DefaultGameModeExperience        ← 兜底默认值
```

> 📄 完整实现见 `代码/LyraGameMode.cpp`

---

### 第 4 步：`SetCurrentExperience()` — 异步加载

**时机**：Component 收到 SetCurrentExperience 调用

```cpp
// ExperienceManagerComponent 内部逻辑（伪代码）：
void ULyraExperienceManagerComponent::SetCurrentExperience(FPrimaryAssetId ExperienceId)
{
	// 1. 通过 AssetManager 异步加载 ExperienceDefinition 资产
	AssetManager.LoadAsset(ExperienceId, /* 回调 */);

	// 2. 加载完成后，解析 ExperienceDefinition 里的 GameFeaturesToEnable
	//    逐个加载对应的 GameFeature 插件
}
```

**关键点**：这是**异步**的！不会阻塞主线程。加载过程中玩家可以看 Loading 画面。

> ⚠️ 本地无此文件源码，需参考 LyraStarterGame 源码 `Source/LyraGame/Experience/LyraExperienceManagerComponent.h`

---

### 第 5 步：GameFeature 插件激活 — Action 开始执行

**时机**：Experience 及其依赖的 GameFeature 插件全部加载完成

```
ExperienceDefinition 加载完成
    │
    ├── 读取 GameFeaturesToEnable: ["ShooterCore", "Teams"]
    │       │
    │       ├── ShooterCore 插件激活 → 注册射击相关能力
    │       └── Teams 插件激活 → 注册队伍相关能力
    │
    ├── 遍历 Actions 列表
    │       │
    │       └── 每个 Action 调用 OnGameFeatureActivating()
    │             ├── 生成 UI Widget
    │             ├── 设置游戏规则
    │             └── 注册 GameplayTag
    │
    └── 遍历 ActionSets 引用
            │
            └── 递归执行 ActionSet 里的 Action
```

**关键点**：Action 的执行顺序是先 Actions 再 ActionSets，都是同步执行的。

---

### 第 6 步：`OnExperienceLoaded()` — 广播 + 生成 Pawn

**时机**：Experience 完全加载并激活后，回调 GameMode

```cpp
void ALyraGameMode::OnExperienceLoaded(const ULyraExperienceDefinition* Experience)
{
	CurrentExperience = Experience;

	// 广播委托——其他系统可以监听这个事件
	OnExperienceLoadedDelegate.Broadcast(Experience);

	// 为所有已经存在的玩家生成 Pawn
	for (FConstPlayerControllerIterator It = GetWorld()->GetPlayerControllerIterator(); It; ++It)
	{
		APlayerController* PC = It->Get();
		if (PC && !PC->GetPawn())
		{
			SpawnDefaultPawnAtTransform(PC, PC->GetSpawnLocation());
		}
	}
}
```

**关键点**：
- 委托广播让其他系统（如 BotCreationComponent）也能响应
- 遍历已有 PlayerController，为没有 Pawn 的生成角色

> 📄 完整实现见 `代码/LyraGameMode.cpp`

---

### 第 7 步：`GetDefaultPawnClassForController()` — 动态决定 Pawn 类型

**时机**：`SpawnDefaultPawnAtTransform` 内部调用

```cpp
UClass* ALyraGameMode::GetDefaultPawnClassForController_Implementation(AController* InController)
{
	if (const ULyraPawnData* PawnData = GetPawnDataForController(InController))
	{
		if (PawnData->PawnClass)
		{
			return PawnData->PawnClass;  // 用 Experience 配置的 Pawn 类型！
		}
	}
	return Super::GetDefaultPawnClassForController_Implementation(InController);
}
```

**关键点**：这就是"数据驱动"的核心体现——Pawn 类型不是硬编码的，而是从 Experience 配置里读的。

> 📄 完整实现见 `代码/LyraGameMode.cpp`

---

### 第 8 步：`SpawnDefaultPawnAtTransform()` — 生成角色

**时机**：确定 Pawn 类型后，在出生点生成角色

```cpp
APawn* ALyraGameMode::SpawnDefaultPawnAtTransform_Implementation(AController* NewPlayer, const FTransform& SpawnTransform)
{
	UClass* PawnClass = GetDefaultPawnClassForController(NewPlayer);
	if (PawnClass)
	{
		return GetWorld()->SpawnActor<APawn>(PawnClass, SpawnTransform);
	}
	return Super::SpawnDefaultPawnAtTransform_Implementation(NewPlayer, SpawnTransform);
}
```

**关键点**：最终调用引擎的 `SpawnActor` 生成角色实例。此时玩家就拥有角色了！

> 📄 完整实现见 `代码/LyraGameMode.cpp`


---

## 一句话总结

> **GameMode 发起 → Component 异步加载 → Action 激活 → Pawn 生成，8 步完成从启动到角色就绪。**

整个过程是异步的，不会卡住主线程。每个环节都有明确的职责分工。

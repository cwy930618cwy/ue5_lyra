# GAS 核心概念速查

## 架构图

```
Player Character
    ├── AbilitySystemComponent (ASC) <- 管理所有技能/属性
    │     ├── AttributeSet (AS)      <- 数据容器 (HP/MP/Stamina等)
    │     ├── GameplayAbility (GA)   <- 技能定义（做什么）
    │     ├── GameplayEffect (GE)    <- 效果修改（改什么）
    │     └── GameplayTag (GT)       <- 标签系统（谁影响谁）
```

## 五大核心类

### 1. AbilitySystemComponent (ASC)
- 角色：GAS 的大脑，挂载在 Actor 上
- 职责：管理所有 GA/GE/AS/Tag
- 放置位置：本教程放在 Character 上（简单方案），Lyra 放在 PlayerState 上（网络复制更优）

### 2. AttributeSet (AS)
- 角色：数据容器
- 职责：存储 HP、MP、Stamina 等属性值
- 关键宏：ATTRIBUTE_ACCESSORS 生成 Getter/Setter

### 3. GameplayAbility (GA)
- 角色：技能定义
- 生命周期：CanActivate -> ActivateAbility -> CommitAbility -> EndAbility

### 4. GameplayEffect (GE)
- DurationPolicy：
  - Instant：即时生效（伤害、治疗）
  - Duration：持续一段时间（Buff）
  - Infinite：永久生效直到移除（被动技能）

### 5. GameplayTag
- 格式：点分字符串，支持层级关系
- 示例："State.Attacking"、"Effect.Damage"

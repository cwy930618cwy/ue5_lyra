## 二、GAS 技能系统

### 2.1 ASC 放置位置

**Lyra 把 ASC 放在 PlayerState 上**，不是 Character 上。

```cpp
// LyraPlayerState.h
class ALyraPlayerState : public AModularPlayerState, public IAbilitySystemInterface
{
    UPROPERTY(VisibleAnywhere, Category = "Lyra|PlayerState")
    TObjectPtr<ULyraAbilitySystemComponent> AbilitySystemComponent;
};
```

**原因**：PlayerState 在玩家断线重连时不会销毁，ASC 和其上的 GE/属性得以保留。

### 2.2 GA 基类（LyraGameplayAbility）

```cpp
// LyraGameplayAbility.cpp 构造函数
InstancingPolicy = EGameplayAbilityInstancingPolicy::InstancedPerActor;
NetExecutionPolicy = EGameplayAbilityNetExecutionPolicy::LocalPredicted;
ReplicationPolicy = EGameplayAbilityReplicationPolicy::ReplicateNo;
```

**关键方法**：
- `CanChangeInstanceMappingOnActivation()` — 控制激活时是否切换实例映射
- `GetAbilityLevel()` — 从 Spec 获取等级
- `GetCurrentMontage()` — 获取当前播放的蒙太奇

### 2.3 技能授予方式：AbilitySet

Lyra **不在角色上硬编码 GiveAbility**，而是通过 **AbilitySet DataAsset** 批量授予：

```cpp
// LyraAbilitySet.h
UCLASS(BlueprintType, Const)
class ULyraAbilitySet : public UPrimaryDataAsset
{
    // 要授予的 GA 列表（每个带 InputTag）
    UPROPERTY(EditDefaultsOnly)
    TArray<FLyraAbilitySet_GameplayAbility> GrantedGameplayAbilities;
    
    // 要授予的 GE 列表
    UPROPERTY(EditDefaultsOnly)
    TArray<FLyraAbilitySet_GameplayEffect> GrantedGameplayEffects;
    
    // 要授予的属性集
    UPROPERTY(EditDefaultsOnly)
    TArray<FLyraAbilitySet_AttributeSet> GrantedAttributes;
};
```

**授予流程**：
```cpp
// LyraAbilitySet.cpp
void ULyraAbilitySet::GiveToAbilitySystem(ULyraAbilitySystemComponent* LyraASC, ...) const
{
    // 1. 授予 AttributeSet
    for (const FLyraAbilitySet_AttributeSet& SetToGrant : GrantedAttributes)
    {
        UAttributeSet* NewSet = NewObject<UAttributeSet>(LyraASC->GetOwner(), SetToGrant.AttributeSet);
        LyraASC->AddAttributeSetSubobject(NewSet);
    }
    
    // 2. 授予 GA（关键：InputTag 写入 Spec 的动态标签）
    for (const FLyraAbilitySet_GameplayAbility& AbilityToGrant : GrantedGameplayAbilities)
    {
        FGameplayAbilitySpec AbilitySpec(AbilityCDO, AbilityToGrant.AbilityLevel);
        AbilitySpec.SourceObject = SourceObject;
        AbilitySpec.GetDynamicSpecSourceTags().AddTag(AbilityToGrant.InputTag);  // ← 输入绑定用
        LyraASC->GiveAbility(AbilitySpec);
    }
    
    // 3. 应用 GE
    for (const FLyraAbilitySet_GameplayEffect& EffectToGrant : GrantedGameplayEffects)
    {
        LyraASC->ApplyGameplayEffectToSelf(GameplayEffect, EffectLevel, Context);
    }
}
```

### 2.4 输入绑定流程

**输入 → InputTag → GA 激活** 的完整链路：

```
按键按下 → Enhanced Input 触发 InputAction
        → LyraInputComponent::BindAbilityActions 已绑定 InputTag
        → HeroComponent::Input_AbilityInputTagPressed(InputTag)
        → ASC->TryActivateAbilitiesByTag(FGameplayTagContainer(InputTag))
        → GA 激活
```

**LyraInputConfig** 定义 InputAction → InputTag 的映射：
```cpp
// LyraInputConfig.h
USTRUCT(BlueprintType)
struct FLyraInputAction
{
    UPROPERTY(EditDefaultsOnly)
    TObjectPtr<const UInputAction> InputAction;
    
    UPROPERTY(EditDefaultsOnly, Meta = (Categories = "InputTag"))
    FGameplayTag InputTag;
};
```

**LyraInputComponent** 提供模板绑定函数：
```cpp
// 绑定能力输入（Pressed + Released）
template<class UserClass, typename PressedFuncType, typename ReleasedFuncType>
void BindAbilityActions(const ULyraInputConfig* InputConfig, UserClass* Object, 
                        PressedFuncType PressedFunc, ReleasedFuncType ReleasedFunc, 
                        TArray<uint32>& BindHandles);
```

### 2.5 蒙太奇播放与 EndAbility

Lyra 使用 **PlayMontageAndWait** 异步任务：
```cpp
// GA 内部播放蒙太奇并等待结束
UAbilityTask_PlayMontageAndWait* Task = 
    UAbilityTask_PlayMontageAndWait::CreatePlayMontageAndWaitProxy(
        this, NAME_None, MontageToPlay, RateOverride);
Task->OnComplete.AddDynamic(this, &ThisClass::EndAbility);
Task->ReadyForActivation();
```

## 三、Experience 系统

### 3.1 核心概念

Experience 是 Lyra 的**数据驱动游戏模式系统**：

```cpp
// LyraExperienceDefinition.h
UCLASS(BlueprintType, Const)
class ULyraExperienceDefinition : public UPrimaryDataAsset
{
    // 要启用的 GameFeature 插件列表
    TArray<FString> GameFeaturesToEnable;
    
    // 默认 Pawn 数据
    TObjectPtr<const ULyraPawnData> DefaultPawnData;
    
    // 要执行的 Action 列表
    TArray<TObjectPtr<UGameFeatureAction>> Actions;
};
```

### 3.2 PawnData

PawnData 定义角色的所有属性：
```cpp
// LyraPawnData.h
UCLASS(BlueprintType, Const)
class ULyraPawnData : public UPrimaryDataAsset
{
    // 角色类
    TSubclassOf<APawn> PawnClass;
    
    // 要授予的 AbilitySet 列表 ← 技能在这里配置！
    TArray<TObjectPtr<ULyraAbilitySet>> AbilitySets;
    
    // 输入配置
    TObjectPtr<ULyraInputConfig> InputConfig;
    
    // 默认相机模式
    TSubclassOf<ULyraCameraMode> DefaultCameraMode;
};
```

### 3.3 初始化流程

```
ExperienceManagerComponent 加载 ExperienceDefinition
    → 启用 GameFeature 插件
    → 执行 Actions（如添加输入映射、生成 Actor）
    → 设置 DefaultPawnData
    → PawnExtensionComponent 协调各组件初始化
    → HeroComponent 绑定输入
    → ASC 就绪，AbilitySet 授予完成
```

## 四、InitState 四阶段初始化

Lyra 使用 GameplayTag 标记初始化状态：

```cpp
// LyraGameplayTags.cpp
UE_DEFINE_GAMEPLAY_TAG_COMMENT(InitState_Spawned, "InitState.Spawned", 
    "1: Actor/component has initially spawned");
UE_DEFINE_GAMEPLAY_TAG_COMMENT(InitState_DataAvailable, "InitState.DataAvailable", 
    "2: All required data has been loaded/replicated");
UE_DEFINE_GAMEPLAY_TAG_COMMENT(InitState_DataInitialized, "InitState.DataInitialized", 
    "3: Data initialized, but not ready for gameplay");
UE_DEFINE_GAMEPLAY_TAG_COMMENT(InitState_GameplayReady, "InitState.GameplayReady", 
    "4: Fully ready for active gameplay");
```

**状态转换**：`Spawned → DataAvailable → DataInitialized → GameplayReady`

## 七、关键设计原则

1. **数据驱动**：一切配置通过 DataAsset（PawnData/AbilitySet/ExperienceDefinition）
2. **组件化**：功能拆分到独立 Component（Hero/PawnExtension/EquipmentManager）
3. **GameplayTag 驱动**：输入、状态、能力都用 Tag 标识
4. **模块化**：GameFeature 插件支持动态加载/卸载
5. **网络优先**：ASC 放 PlayerState、LocalPredicted、FFastArraySerializer 增量复制

---

## 八、与 ue5_lyra 项目的对照

| Lyra 做法 | ue5_lyra 当前做法 | 差异 |
|-----------|------------------|------|
| ASC 放 PlayerState | ASC 放 Character | 简化，单机够用 |
| AbilitySet 批量授予 | 直接 GiveAbility | 简化，后续可扩展 |
| Experience 系统 | 无 | 暂不需要 |
| PlayMontageAndWait | 直接 Montage_Play | 简化，需手动 EndAbility |
| InputTag 绑定 | 直接调用 Attack() | 简化，后续改 GAS 输入 |

## 九、UE5.5 API 变更备忘

| 旧写法（5.4-） | 新写法（5.5+） |
|---|---|
| `EGameplayAbilityInstancingPolicy::PerExecution` | `InstancedPerExecution`（Lyra 用 `InstancedPerActor`） |
| `FGameplayAbilityTriggerData(Source)` 构造 | `FAbilityTriggerData` + `.TriggerSource` 赋值 |

# AI 学习经验记录

> 本目录用于记录 UE5 动作战斗 Demo 开发过程中遇到的问题、解决方案和经验总结。
> 每次对话中遇到的有价值的问题都会分类记录到对应文件中。

## 📁 目录结构

| 文件夹 | 用途 |
|--------|------|
| `01_环境搭建` | UE5 安装、项目配置、插件管理、编译环境等 |
| `02_C++基础框架` | 角色系统、输入系统、移动组件、动画系统等基础框架 |
| `03_GAS技能系统` | AttributeSet、AbilitySystemComponent、GameplayAbility、GE 等 |
| `04_战斗系统` | 伤害计算、连招系统、受击反馈、武器系统等 |
| `05_AI与场景` | 行为树、AI控制器、场景搭建、关卡设计等 |
| `06_工具链与技巧` | Meshy AI、MetaHuman、ActorCore、打包发布等工具使用 |
| `07_踩坑记录` | 各类 Bug、编译错误、运行时问题及解决方案 |

## 📝 记录规范

- 每个问题单独一个 `.md` 文件
- 文件名格式：`YYYYMMDD_问题简述.md`
- 内容包含：问题描述 → 原因分析 → 解决方案 → 参考链接

# T2.2 血条 UI 实时更新

## 目标
按 H/J 键扣血/加血时，UMG 血条（HealthBarWidget）实时跟着变化。

## 当前问题
- `HealthComponent::OnHealthChanged` 监听到了血量变化，但只打印日志
- `HealthBarWidget::SetHealth()` 方法已写好，但没人调用它
- **缺的是：把 HealthComponent 和 HealthBarWidget 连起来**

## 数据流设计

```
用户按 H/J 键
    → BattleCharacter::TestTakeDamage() / TestHeal()
    → ApplyDamage() / Heal()
    → ASC->ApplyGameplayEffectToSelf()
    → HealthSet::PostGameplayEffectExecute() 修改血量
    → ASC 广播属性变化回调
    → HealthComponent::OnHealthChanged() 收到通知
    → 调用 HealthBarWidget->SetHealth(新血量, 最大血量)
    → 血条 ProgressBar 更新显示
```

## 实现方案

### 核心思路
让 HealthComponent 持有 HealthBarWidget 的引用，在 OnHealthChanged 里直接更新 UI。

### 为什么不在 BattleCharacter 里做？
- HealthComponent 已经监听了血量变化（职责清晰）
- UI 更新逻辑应该跟"监听"放在一起，而不是分散到 Character 里
- 后续如果有多个 Widget（血条、数字、Buff图标），都可以在 HealthComponent 里统一管理

## 涉及文件
- `Components/HealthComponent/HealthComponent.h` — 添加 Widget 引用
- `Components/HealthComponent/HealthComponent.cpp` — OnHealthChanged 里调用 SetHealth
- `Controllers/BattlePlayerController.cpp` — BeginPlay 里创建 Widget 并传给 HealthComponent

## 关键点
1. HealthBarWidget 通过 CreateWidget + AddToViewport 创建（已在 PlayerController 中完成）
2. HealthComponent 需要拿到 Widget 的引用（通过 FindComponentByClass 或手动赋值）
3. SetHealth 接收 (CurrentHealth, MaxHealth)，内部算百分比设置 ProgressBar

## 踩坑记录
1. **编译错误 C2248**：`HealthBarWidget` 放在 `protected` 区域，`BattlePlayerController` 外部无法访问 → 移到 `public`
2. **编译错误 C2027**：`HealthComponent.cpp` 只有前向声明没有完整定义，调用 `SetHealth()` 报错 → 加 `#include "UI/HealthBarWidget/HealthBarWidget.h"`
3. **回调不触发**：`HealthComponent` 没挂到角色上（构造函数里没创建）→ 加 `CreateDefaultSubobject<UHealthComponent>()`

## 最终代码改动汇总

### BattleCharacter.h
- 前向声明 `class UHealthComponent;`（第 27 行）
- 成员变量 `TObjectPtr<UHealthComponent> HealthComponent;`（第 126-127 行）

### BattleCharacter.cpp
- include `"Components/HealthComponent/HealthComponent.h"`（第 37 行）
- 构造函数末尾 `HealthComponent = CreateDefaultSubobject<UHealthComponent>(TEXT("HealthComponent"));`（第 193 行）
- TestTakeDamage 里加调试日志确认组件存在

### HealthComponent.h
- 前向声明 `class UHealthBarWidget;`
- public 区域加 `UPROPERTY() UHealthBarWidget* HealthBarWidget;`

### HealthComponent.cpp
- include `"UI/HealthBarWidget/HealthBarWidget.h"`
- OnHealthChanged 末尾调用 `HealthBarWidget->SetHealth(NewHealth, HealthSet->GetMaxHealth())`

### BattlePlayerController.cpp
- include `"Components/HealthComponent/HealthComponent.h"`
- CreateHUD 里通过 FindComponentByClass 找到 HealthComponent 并赋值 Widget

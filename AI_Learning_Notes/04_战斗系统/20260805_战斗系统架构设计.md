# 战斗系统架构设计

## 战斗状态机

```cpp
namespace EABDCombatState {
    enum Type : uint8 {
        Idle,           // 待机（可移动、可攻击）
        Moving,         // 移动中
        Attacking,      // 攻击中（不可打断或有限次可打断）
        Dodging,        // 翻滚闪避中（无敌帧）
        Blocking,       // 格挡中
        HitReacting,    // 受击硬直中
        Dead,           // 死亡
        Stunned,        // 眩晕（控制效果）
        Casting,        // 施放大招中
    };
}
```

## 连击系统时序

```
时间轴 ->

第1击:  [====攻击动画====]
         ^开始          ^InputWindow开始 ^InputWindow结束
                                              v用户按下攻击
第2击:                      [========攻击========]
                                             ^InputWindow开始
                                                                  v按下
第3击:                                                        [===攻击===]

超时重置: 如果 InputWindowEnd 之后 ComboResetTimeout 内没有新输入
          -> ComboIndex 回到 0，下次攻击从头开始
```

### 连击节点数据结构

```cpp
struct FComboNode {
    int32 Index;                    // 第几段
    TSubclassOf<UGameplayAbility> AbilityClass;
    UAnimMontage* Montage;
    float InputWindowBegin;         // 输入窗口起始（秒）
    float InputWindowEnd;           // 输入窗口结束
    float NextComboResetTime;       // 超过这个时间没输入就重置
};
```

## 受击反馈系统

```
ProcessHit(Victim, Damage, HitResult, SourceTags):
    1. ChooseHitReactionMontage()  <- 根据攻击方向选受击动画
    2. ApplyStun()                  <- 应用受击硬直
    3. SpawnHitVFX()                <- 播放受击特效
    4. PlayHitSFX()                 <- 播放受击音效
    5. ApplyCameraShake()           <- 相机震屏
    6. ApplySlowMotion()            <- 时间膨胀（重击时）
```

## 伤害计算流程

```
攻击命中
    -> PerformAttackCheck()（球形检测）
    -> 对每个命中目标:
        -> MakeEffectContext()（创建效果上下文）
        -> AddSourceObject(this)（标记来源）
        -> AddHitResult(Hit)（记录命中信息）
        -> MakeOutgoingSpec(DamageGE, Level, Context)
        -> TargetASC->ApplyGameplayEffectSpecToSelf(Spec)
        -> 目标 Health -= Damage * (1 + ComboBonus)
```

# 战斗系统架构设计

## 战斗状态机

```cpp
namespace EABDCombatState {
    enum Type : uint8 {
        Idle,           // 待机（可移动、可攻击）
        Moving,         // 移动中
        Attacking,      // 攻击中（不可打断或有限次可打断）
        Dodging,        // 翻滚闪避中（无敌帧）
        Blocking,       // 格挡中
        HitReacting,    // 受击硬直中
        Dead,           // 死亡
        Stunned,        // 眩晕（控制效果）
        Casting,        // 施放大招中
    };
}
```

## 连击系统时序

```
时间轴 ->

第1击:  [====攻击动画====]
         ^开始          ^InputWindow开始 ^InputWindow结束
                                              v用户按下攻击
第2击:                      [========攻击========]
                                             ^InputWindow开始
                                                                  v按下
第3击:                                                        [===攻击===]

超时重置: 如果 InputWindowEnd 之后 ComboResetTimeout 内没有新输入
          -> ComboIndex 回到 0，下次攻击从头开始
```

### 连击节点数据结构

```cpp
struct FComboNode {
    int32 Index;                    // 第几段
    TSubclassOf<UGameplayAbility> AbilityClass;
    UAnimMontage* Montage;
    float InputWindowBegin;         // 输入窗口起始（秒）
    float InputWindowEnd;           // 输入窗口结束
    float NextComboResetTime;       // 超过这个时间没输入就重置
};
```

## 受击反馈系统

### 当前实现（Day 5.2 + 5.3）

```
按 H 键 → ApplyDamage → GE 扣血
  → ASC 广播属性变化 → HealthComponent::OnHealthChanged
    → 检测到受伤(Delta < 0)
      → OwnerCharacter->SetCombatState(HitReacting)
        → BattleCharacter 播放 HitReactMontage（受击动画）
      → Timer 0.5秒后 → OnHitReactEnd
        → SetCombatState(Idle)
          → Montage_Stop 停止受击动画
```

**关键代码位置：**
- `HealthComponent::OnHealthChanged` — 受伤检测 + 触发受击状态
- `HealthComponent::OnHitReactEnd` — 硬直结束回调
- `BattleCharacter::SetCombatState` — 状态切换 + 动画播放/停止
- `BattleCharacter::HitReactMontage` — 受击蒙太奇资源（EditDefaultsOnly）

**⚠️ 坑点记录：**
- `SetCombatState` 必须是 public，HealthComponent 外部才能调用
- `FTimerHandle` 局部变量即可，只要回调对象（this）还活着 Timer 就会触发
- 枚举值名字是 `HitReacting` 不是 `HitStun`（容易写错）
- 受击期间 `CurrentCombatState != Idle`，Attack() 自动被拦截，无需额外判断

### 完整受击反馈（后续扩展）

```
ProcessHit(Victim, Damage, HitResult, SourceTags):
    1. ChooseHitReactionMontage()  <- 根据攻击方向选受击动画
    2. ApplyStun()                  <- 应用受击硬直
    3. SpawnHitVFX()                <- 播放受击特效
    4. PlayHitSFX()                 <- 播放受击音效
    5. ApplyCameraShake()           <- 相机震屏
    6. ApplySlowMotion()            <- 时间膨胀（重击时）
```

## 伤害计算流程

```
攻击命中
    -> PerformAttackCheck()（球形检测）
    -> 对每个命中目标:
        -> MakeEffectContext()（创建效果上下文）
        -> AddSourceObject(this)（标记来源）
        -> AddHitResult(Hit)（记录命中信息）
        -> MakeOutgoingSpec(DamageGE, Level, Context)
        -> TargetASC->ApplyGameplayEffectSpecToSelf(Spec)
        -> 目标 Health -= Damage * (1 + ComboBonus)
```

```

    └── CreateHUD → 创建 UHealthBarWidget + 赋值给 HealthComponent->HealthBarWidget
```

## 关键设计决策

### 1. 受击期间自动禁止攻击
`Attack()` 方法开头检查 `CurrentCombatState != Idle` 直接 return。
受击时状态是 `HitReacting`，所以玩家无法在受击时攻击。无需额外逻辑。

### 2. 受击蒙太奇播放/停止时机
- **播放**：`SetCombatState(HitReacting)` 时立即播放
- **停止**：0.5s 后 `OnHitReactEnd` → `SetCombatState(Idle)`，此时检测到"从 HitReacting 离开"，调用 `Montage_Stop(0.25f)` 混合停止

### 3. 伤害走 GE 流程而非直接改属性
外部调用 `ApplyDamage(正数)` → 内部转负数 → 通过 `Data.Damage` Tag 的 SetByCaller 机制 → GE 执行扣血 → `PreAttributeChange` 钳制 → `OnHealthChanged` 回调触发受击反馈。这样后续可以方便地加入护甲、减伤 Buff 等。

### 4. HealthComponent 独立于 Character
血量监听、受击反馈、血条更新都放在 HealthComponent 里，Character 只负责暴露接口（GetAbilitySystemComponent、GetHealthSet、SetCombatState）。职责分离，后续加 Buff 图标、伤害数字等都在 HealthComponent 扩展即可。
